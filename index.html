¿Que es el desarrollo web?

El desarrollo web consiste en crear páginas y aplicaciones para Internet utilizando tecnologías como HTML, CSS y JavaScript, etc.

HTML: estructura

HTML permite organizar los textos, títulos, imágenes, enlaces y demás elementos de una página web.

Diseño y programación

CSS permite personalizar los colores, tamaños, márgenes, bordes y distribución de los elementos de un sitio web.

CSS: presentación

Mediante las propiedades float, clear y clearfix podemos organizar cajas y columnas dentro de una página web.
